# 한자 뜻 배경 그림 — 시험 자료

2026-10-10 기준 Step 2 · Lesson 2 단어 64개에 쓰인 고유 한자 56자만 제공합니다. 예문에만 나오는 한자 81자는 이번 시험에 포함하지 않았습니다. 해당 글자는 다른 레슨에서 열어도 같은 그림이 표시됩니다.

직접 작성한 단색 SVG 선 그림입니다. 외부 서비스의 그림을 복사하거나 실행 중에 AI로 생성하지 않습니다. 한자의 일부 부수가 아닌 **글자 전체의 뜻 중 하나**를 연상시키는 장면을 각각 정했습니다. 어원이나 모든 뜻을 설명하는 그림은 아닙니다. 복합어 전체의 뜻으로 바꾸지 않습니다(예: 帽는 모자, 子는 아이; 風은 바람, 邪는 그릇됨).

- 파일 이름: 한 글자의 Unicode 코드 포인트를 소문자 16진수로 표기합니다(備 → `5099.svg`).
- 대응하는 의미·장면 설명: `src/data/kanji-illustrations.json`.
- 의미 검토: 저장된 한자 사전의 한국어 훈음·KANJIDIC2 뜻과 해당 레슨의 용례를 참고했습니다. 한국어 훈음과 일본어 용례의 대표 뜻이 다를 수 있습니다. 利는 날카로운 칼, 坊는 동네, 準은 같은 기준선에 맞춘 높이, 科는 분야별 구분, 研은 갈고 닦기, 究는 깊이 살피기로 구별했습니다.
- `viewBox="0 0 100 100"`, 투명 배경, 단색 선만 사용합니다. 그림 안에 한자나 설명 문장을 넣지 않습니다. 정확한 글자와 획순은 기존 KanjiVG 데이터로 별도 표시합니다.
- 설정의 **한자 뜻 배경 그림**은 기본 꺼짐입니다. 켜기·끄기는 이 브라우저에 저장합니다. 저장이 차단되면 현재 실행에서만 유지합니다.
- 켰을 때 지원하는 글자의 그림만 요청합니다. 그림이 없거나 요청이 실패해도 뜻·읽기·획순은 그대로 표시합니다. 받은 그림은 기존 서비스 워커가 캐시해 오프라인에서도 사용할 수 있습니다.
- 이 자료는 1회 제작한 정적 파일이며 자동 생성 배치·정기 GitHub Action을 두지 않습니다. 향후 확대·유지·제거는 학습자가 직접 비교한 뒤 결정합니다.

검증: `npm test`로 설정 저장·변경 알림·시험 범위·파일 연결을 검사합니다. 그림과 획순이 겹쳤을 때의 식별성은 모바일 크기의 라이트·다크 화면에서 별도로 확인합니다. 단어가 추가되어 시험 범위를 바꾸게 되면 대응 자료와 범위 테스트도 함께 갱신합니다.
